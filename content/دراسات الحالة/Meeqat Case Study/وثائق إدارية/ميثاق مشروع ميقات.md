> **الإصدار:** 1.0 (مسوّدة للاعتماد) · **مُعدّة في:** دراسة الحالة · **تحتاج اعتماد:** ⬜
> الحقول المعلَّمة `⬜ يُملأ` تحتاج قرار صاحب المشروع؛ الباقي مستخرَج من واقع المشروع.

## 1) هوية المشروع

| البند | القيمة |
| --- | --- |
| اسم المشروع | **ميقات** — منصّة إدارة الفعاليات كخدمة |
| النوع | منتج SaaS متعدّد المستأجرين (لا مشروع عميل واحد) |
| الراعي / صاحب القرار | ⬜ يُملأ |
| قائد المشروع | ⬜ يُملأ |
| تاريخ البدء الفعلي | ⬜ يُملأ |
| الحالة | قيد التطوير النشط؛ لم يُطلق تجاريًّا بعد |

## 2) مبرّر العمل

> [!abstract] لماذا هذا المشروع موجود؟
> **المشكلة:** الجهات المنظِّمة تدير فعالياتها بجداول وحضور ورقي، فتفقد دقّة البيانات، وتصدر الشهادات يدويًّا، ولا تملك دليلًا موثوقًا على من حضر.
> **الفرصة:** هذه الجهات تكرّر فعالياتها، فما يُبنى مرّة يخدم مرارًا ⇒ **منتج** لا خدمة لمرّة واحدة.
> **البديل المرفوض:** نظام مخصّص لكل جهة (كلفة تتضاعف بلا تراكم) أو منصّة أجنبية (لا تخدم العربية ولا سياق الاعتماد المحلّي).

## 3) الأهداف

| # | الهدف | معيار القياس |
| --- | --- | --- |
| G1 | رحلة مشارك كاملة بلا ورق | من التسجيل إلى الشهادة داخل النظام |
| G2 | حضور موثوق وقابل للتدقيق | سجل حركة بمناطق وأيام ومسؤول مسح |
| G3 | إصدار شهادات آلي مشروط | صفر إصدار يدوي |
| G4 | عزل تامّ بين الجهات | صفر حادثة تسريب |
| G5 | تشغيل جهتين على الأقل بلا تدخّل تقني | ⬜ التاريخ المستهدف |

## 4) النطاق العالي

> [!success] داخل النطاق
> إدارة الجهات والمستخدمين والأدوار · إنشاء الفعاليات وأيامها ومناطقها · نموذج تسجيل ديناميكي · تذكرة QR وبطاقة دخول · ماسح حضور داخل المتصفّح · تذكيرات مجدولة · محرّك نماذج وتقييم · شهادات PDF ورابط تحقّق · بوّابة خدمة ذاتية للمشارك · تحليلات وتصدير · دعم العربية والإنجليزية.

> [!failure] خارج النطاق (هذه الدورة)
> بوّابات دفع وبيع تذاكر · تطبيق جوّال أصلي · بثّ مباشر للفعاليات · تكامل مع أنظمة اعتماد مهني خارجية · تطبيق مورّد/خدمات لوجستية · ذكاء اصطناعي توليدي داخل المنصّة.

## 5) معايير النجاح

| # | المعيار | العتبة |
| --- | --- | --- |
| S1 | فعالية حقيقية كاملة نُفِّذت عبر المنصّة | 1 فعالية |
| S2 | نسبة نجاح تسليم رسائل البريد | ≥ 95% |
| S3 | أعطال حرجة أثناء ساعات الفعالية | صفر |
| S4 | مشاركون استلموا شهاداتهم بلا طلب دعم | ≥ 70% |
| S5 | زمن إعداد الفعالية الكاملة | ≤ 60 دقيقة |
| S6 | بنود دليل الاختبار المغلقة قبل الإطلاق | 100% |

| القيد | الأثر |
| --- | --- |
| فريق محدود جدًّا (⬜ العدد) | لا توازٍ في التنفيذ؛ الأولوية حاسمة |
